### 🧩 Reverse Engineering / Game Archive Tools

Bộ GUI tool giải nén – đóng gói – xem/sửa các định dạng archive độc quyền của nhiều tựa game:

- **PAK-ChinhDo-GUI** — nén/giải nén Pak game Chinh Đồ (ZhengTu Online)
- **PAK-PhongThan-GUI** — nén/giải nén Pak game Phong Thần
- **Rez-CrossFire-GUI** — nén/giải nén Rez game Đột Kích (CrossFire, LithTech)
- **SPR-VLTK-GUI** — xem/sửa Spr game VLTK 1&2, Kiếm Thế, Phong Thần
- **Wad-LOL-GUI** — nén/giải nén Wad game LMHT (Riot WAD)
- Ngoài ra: EA `.big` (EASF/ChunkZip), AoE DRS/SLP, XPAK `.pak`, ZPack `.pack`, SPR Kingsoft Sword3, AXP, và reverse engineering sâu định dạng animation PopTag/Crazy Arcade (EmoTE/CharTE, IC bytecode, bone table)

### 🛠 Utilities

- **2CongLC-IME** — Bộ gõ tiếng Việt (Telex, hỗ trợ TCVN3/VNI, tự tắt khi vào game)
- **GameBot** — Bot với hệ thống Record & Replay đọc tọa độ từ memory game, lưu dữ liệu JSON
